# Arkanoid 3D

A 3D take on the classic Breakout/Arkanoid. Control the paddle, break the bricks and collect power-ups.

## Features
- Paddle, ball and brick gameplay with a dead zone
- Power-ups: expand bar, magnet, multiball
- Generic **object pool** (balls and upgrades)
- Game state management and UI

## Tech
Unity 2022.3.16f1 · C# · TextMesh Pro

## Run it
1. Open the `Arkanoid3D/` subfolder with Unity 2022.3.16f1.
2. Open `Assets/Scenes/SampleScene` and press Play.
